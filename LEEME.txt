IMÁGENES DE LAS ASCENDENCIAS
=============================

Pon aquí una imagen por ascendencia con el nombre de archivo indicado.
Formatos admitidos: .webp, .jpg o .png  (por ejemplo: elfo.webp, enano.jpg)

Recomendaciones:
- Formato vertical o cuadrado; se recorta para encajar (en las tarjetas, cuadrado;
  en la ficha, 3:4).
- Unos 600×800 px y menos de 200 KB cada una para que la app cargue rápido
  (WebP es el formato que menos ocupa).
- Si una ascendencia no tiene imagen, simplemente no se muestra nada.
